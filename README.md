## 🕹️ Overview

EDuke32 is the most feature-rich Duke3D source port, supporting high-resolution assets, a scripting language (CON), and the Polymer renderer for modern visuals.

Whether you're a newcomer or a veteran, EDuke32 provides the tools you need to get the most out of your gaming tools experience. Designed for Windows and macOS, it delivers a seamless, high-performance workflow.

## ✨ Key Features

| Feature | Description |
|---|---|
| **Polymer Renderer** | OpenGL renderer with dynamic lighting and shadow mapping |
| **HRP Support** | High-resolution texture and model pack compatibility |
| **CON Scripting** | Extended scripting API for complex gameplay and mod programming |
| **HRP Installer** | Built-in downloader and installer for the High Res Pack |
